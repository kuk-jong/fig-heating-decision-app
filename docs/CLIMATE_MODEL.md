# 연간 사인 기온모형 계산·데이터 명세

개정일: 2026-10-20. PR #2의 수정 버전 기준. 운영 서비스 반영 여부는 별도이다.
이 명세와 UML 개정은 생성형 AI를 활용해 작성했다.

## 1. 변경 목적

이전 CSV 처리는 겨울 월평균 일최저기온의 평균을 기준온도로 둔 뒤 반주기 사인을 빼서, 입력자료보다 기온 평균을 추가로 낮추었다. 이번 변경은 계절 곡선을 관측자료에 직접 적합하여 계수 정의의 불일치를 해소한다. 기온 회귀만으로 난방비의 실측 정확성을 입증하는 것은 아니다.

## 2. 식과 계수

```text
P = 365.2425일
C = 2π / P
x(date) = (연중 일번호 - 1) × P / 해당 연도의 일수
T(date) = A + B sin(C x(date) + D)
```

| 계수 | 정의 | 산출 |
|---|---|---|
| A | 연간 곡선의 중심온도(℃) | 회귀 절편 |
| B | 0 이상인 진폭(℃) | hypot(βs, βc) |
| C | 각주파수(rad/일) | 연간 주기로 고정 |
| D | 위상(rad) | atan2(βc, βs) |

내부 회귀는 `T = β0 + βs sin(Cx) + βc cos(Cx)`를 `numpy.linalg.lstsq`로 적합한다. B가 1e-10 이하이면 B와 D를 0으로 둔다. A는 겨울만의 평균온도가 아니다. B>0일 때 최저점은 `Cx+D = -π/2 (mod 2π)` 조건을 만족한다.

절편을 포함하므로 **회귀에 사용한 관측일에서의 적합값 평균은 관측 평균과 일치**한다(부동소수점 오차 제외). 관측일 분포와 다른 120일 예측 구간의 평균까지 동일하다는 뜻은 아니다. 현재 날짜 좌표는 윤년·평년을 같은 연간 위상으로 정규화한다.

## 3. 입력 CSV 계약

| 컬럼 | 형식·단위 | 처리 |
|---|---|---|
| region | 화면 지역명과 같은 문자열 | 앞뒤 공백 제거 후 선택 지역만 추출 |
| date | 시간대 없는 YYYY-MM-DD | 잘못된 날짜 제외, 같은 날짜는 한 관측일로 집계 |
| min_temp | 일최저기온, ℃ | 숫자 변환, 결측·무한값 제외 |

- 겨울 자료로 한정하지 않고 선택 지역의 전체 계절 자료를 사용한다.
- 동일 날짜의 중복 기온은 평균한다. 관측소 구분·품질 플래그 검증은 아직 없다.
- 유효 관측일 3일 이상, 서로 다른 연중 위치 3개 이상, 계절 범위 60일 이상이 필요하다.
- 계절 범위는 연중 좌표의 원형 간격 중 최대 공백을 전체 주기에서 뺀 값이다. 11월~2월처럼 연말을 지나가는 자료도 계산할 수 있다.
- 설계행렬 rank가 3보다 작거나 조건수가 1e6을 초과하면 적합을 중단한다.
- 12개월 미만이거나 30관측일 미만이면 자료 제한 경고를 표시한다. 최소 요건은 정확도 보장이 아니다.
- 업로드 재실행 시 파일 포인터를 처음으로 이동한다.
- CSV가 잘못되었으면 분석을 중단한다. 업로드를 해제하거나 자료를 수정한 뒤 실행한다.

`01. 최초 파이썬 앱/climate_csv_template.csv`는 형식·동작 확인용 **합성자료**이다. 실측·기상청 관측자료가 아니며 실제 의사결정용으로 사용하지 않는다. 실제 자료로 교체할 때 출처·관측소·기간을 별도로 기록한다.

## 4. 자료 출처 분기

| 조건 | 모형 | 화면 표시 |
|---|---|---|
| 유효한 CSV | 일별 관측자료 OLS 회귀 | 관측일 수·계수·RMSE·R²·곡선 |
| CSV 없음 | 기존 base/amp 가정곡선의 연간식 근사 | 관측자료 미적용 경고 |
| 잘못된 CSV | 모형을 적용하지 않음 | 오류 및 분석 중단 |

내장 지역 계수는 새 관측자료로 재추정하지 않았다. 이전 가정곡선에서 생성한 합성값에 회귀한 것이므로 기존 가정의 편향까지 해소했다고 주장하지 않는다. 자료 없는 상태에서 관측 기반 계수를 임의로 만들지 않는다.

## 5. 난방비 연결 및 경계

현재 계산 기간은 2025-11-01~2026-02-28의 고정 120일이다.
각 날짜에 동일한 회귀모형을 적용한 뒤 `max(설정온도-T, 0)`으로 온도차를 계산한다. 양의 온도차일 때 가온시간 14시간을 사용한다. 외피면적·U값·기밀도·방풍벽 보정과 연료 열량·효율·단가, 전기 기본요금 산식은 유지한다. 민감도 분석에서도 계수는 재적합하지 않고 같은 모형을 사용한다.

- 일최저기온은 14시간 가온기간의 평균 외기온과 다르다.
- 날짜별 실제 날씨·한파·실시간 예보를 예측하는 모형은 아니다.
- RMSE와 R²는 적합에 사용한 자료 기준이며 독립연도 성능이 아니다.
- 겨울 이외 자료가 없으면 연간 A·B·D의 불확실성이 커질 수 있다.
- 회귀 잔차, 한파 극값, 시간별 온도와 일별 목표온도 변경은 난방비에 추가 반영되지 않는다.
- U값과 열량의 단위 일치, 겨울 기타 경영비, 매출 계절가중치 정규화 등은 이번 변경 범위 밖이다.
