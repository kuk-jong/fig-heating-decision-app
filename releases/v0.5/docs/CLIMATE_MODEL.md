# 주별 하루 기온모형과 시간별 난방부하 명세

버전 0.6.1 / 2026-10-21. 실제 배포 경로 호환성을 위해 폴더는 releases/v0.5를 유지한다.
이번 구현·문서·UML에는 생성형 AI를 활용했다. 기존 등록 신청본·원본판·기존 3D판은 변경하지 않는다.

## 1. 자료와 범위

제공된 전남 시간별 CSV에서 최근 10개 연도인 2016~2025년을 사용한다. 관측지는 15개 시군 20개이며, 강진은 2017-03-31 이후 자료만 존재한다. 중첩 복사본과 kangin.csv 변환본을 중복 합산하지 않는다.

원본의 `평균기온`은 시각별 행의 평균기온 컬럼이다. 하루 평균온도를 24회 반복하는 방식이 아니다. 원자료를 배포하지 않고 지역·주차별 회귀계수·관측수·기초 진단만 `data/weekly_weather.json`에 포함한다. 근거·품질·출처 파일 해시는 함께 보존한다.

## 2. 전처리

- UTF-8 BOM 및 CP949를 지원하며 한국어 설명행 뒤의 `날짜,평균기온` 헤더를 찾는다.
- 표준 업로드는 `datetime,temp_mean` 또는 `date,temp_mean`이다. 한 관측지 자료만 허용한다.
- 무효 날짜, 결측·비유한 기온, -60~60℃ 범위 밖 기온을 제외한다. 이 범위검사는 기본 오류 점검이며 센서 품질검증은 아니다.
- 시간대 없는 현지 시각을 사용한다. 동일 시간의 중복은 평균한다. 분 단위 자료는 시간별로 집계한다.
- 결측을 0℃로 채우거나 장기간 보간하지 않는다.
- 시군과 내장 관측지가 다르거나 업로드 region이 다른 시군이면 오류를 표시한다. 관측자료가 없는 지역은 업로드가 필요하며 다른 지역으로 대체하지 않는다.

## 3. 주차와 회귀식

계절 주차는 ISO 주차가 아니다. 1월 1~7일이 1주차이며 7일 단위로 구분한다. 마지막 52주차는 12월 24~31일(8일)이다. 윤일 2월 29일은 2월 28일과 같은 연중 좌표로 묶는다.

각 관측지·주차·시각에 대해 먼저 연도별 관측 평균을 계산하고, 연도별 평균들을 동일 가중치로 평균한다. 관측이 많은 연도가 특정 시각을 과도하게 지배하지 않게 한다. 각 시각에서 3개 이상의 유효 관측값과 24시간 자료가 모두 있는 주차만 적합한다.

```text
T_w(h) = a_w + s_w sin(2πh/24) + c_w cos(2πh/24)
       = a_w + b_w sin(2πh/24 + φ_w)
b_w = hypot(s_w,c_w), φ_w = atan2(c_w,s_w)
```

각 주차의 24개 시간대 대표 평균에 절편·사인·코사인 최소제곱 회귀를 적용한다. 같은 주차에는 같은 하루 함수를 사용하고 다음 주차에 함수를 변경한다. 주 경계에서 함수가 불연속일 수 있으며 현재는 보간하지 않는다. 계수·적합도·기온곡선은 내부 계산용이며 결과 화면에는 표시하지 않는다.

`load_catalog`는 내장 계수, `model_from_upload`는 사용자가 업로드한 관측자료에서 같은 형식의 모형을 만든다. 겨울 분석에 필요한 주차가 하나라도 없으면 분석을 중단한다.

## 4. 가온시간과 작기

가온시간은 사용자가 고정 입력하지 않는다. 겨울 작기 시작연도만 선택한다. 하루 0~23시 전체를 평가하여 외기가 설정온도보다 낮은 각 시간의 난방부하를 합산한다. 설정온도 이상인 시간의 부하는 0이다. 따라서 가온시간은 입력값이 아니라 계산 결과이며, 하루 종일 가온하도록 강제하는 뜻이 아니다.

작기는 선택 연도 11월 1일부터 다음 연도 2월 마지막 날까지다. 윤년 2월 29일도 포함한다. 평균 가온시간은 양의 온도차를 가진 시간 수를 작기 일수로 나눈 값이다. 이전 세션의 시작 시각·14시간 입력이 남아 있어도 앱의 열부하 계산에서는 무시한다.

## 5. 열부하·연료비 단위

```text
시간별 부하(kW) = 외피면적(㎡) × U(W/㎡·K) × max(설정온도 - T_w(h),0)
                  × 기밀도계수 × 방풍벽계수 / 1000
작기 유효열량(kWh) = 시간별 부하(kW) × 1시간을 합산
연료량 = 유효열량 / ((연료발열량 kcal/단위 / 860 kcal/kWh) × 효율)
연료비 = 연료량 × 단가
```

U값은 W/(㎡·K) 가정으로 명시한다. 예: 100㎡ × 2W/(㎡·K) × 5℃ = 1kW이며 14시간이면 14kWh이다. 경유는 8,500kcal/L와 효율 0.85, 전기는 860kcal/kWh와 효율 0.98의 기존 가정이다.
전기 기본요금은 작기 최대 입력전력(kW = 최대 유효부하/효율)에 1,150원/kW·월과 4개월을 곱한다. 실제 계약전력·월별 청구를 그대로 재현하는 것은 아니다.

이전 일최저기온×14시간 방식에서는 U와 열량의 단위 환산이 명시되지 않았다. 이번 난방비 차이는 시간별 온도 적용과 W→kWh 환산을 함께 반영한 결과이다. 생산량·가격·경영비·감가상각, 겨울 매출 계절가중치는 유지한다. 과거 수치와 단순 비교할 때 이 차이를 구분한다.

## 7. 검증·한계

- [자료·독립연도 검증](WEEKLY_WEATHER_VALIDATION.md): 2025년 기온은 2016~2024년 곡선으로 별도 평가한다.
- 평균 대표곡선은 한파·날씨 잔차를 평활화한다. 겨울 관측시각의 난방도시와 곡선 난방도시를 동일 조건에서 비교한 값은 특정 설정온도·시간대에만 해당한다.
- U·기밀도·방풍벽·효율·단가는 가정이다. 실측 연료 사용량·난방비 검증은 별도다.
- 3D 식재·설비는 예시이며 생산량·투자비·온실 열수지와 별도로 표시한다.
- 기존 등록 제출자료는 유지한다. 실제 라이브 서비스에는 배포 브랜치 자동 재배포 후 적용된다.

현재 버전의 난방 판단은 시간별 대표 외기온을 기준으로 한다. 실제 온실 내부의 일사·축열·환기·난방기 동작까지 재현하는 제어 시뮬레이터는 아니다.
